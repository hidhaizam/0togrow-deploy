# Otogrow Content Repurposing Bot

A Telegram bot that converts video transcripts into short-form video scripts and AI-generated posters for content review.

## Features

- Generates 5 short-form video scripts from a transcript.
- Provides Approve, Regenerate, and Reject options.
- Generates AI posters.
- Maintains script history.
- Lists approved scripts using the `/approved` command.
- Supports the `/start` and `/history` commands.
- Deployed on Vercel.

## Tech Stack

- Python
- Telegram Bot API
- Vercel
- GitHub
- Pillow for image processing

## Deployment

The application is deployed on Vercel.

## Testing

The main bot functions have been tested, including script generation, review buttons, history, approved scripts, and poster generation.

## Notes

Long-transcript handling, transcript-grounded accuracy checks, access restrictions, and testing with two real transcripts of at least 30 minutes should be verified before claiming full compliance with the assessment requirements.
